# Memory Notes CLI

A simple command-line notes application written in C.

## Features

- Add notes
- View saved notes
- Simple menu-based interface
- Multi-file project structure

## Project Structure

```txt
include/   Header files
src/       Source files
data/      Data storage
```

## Build

```bash
make
```

## Run

```bash
./memory-notes-cli
```

## Purpose

This project was made for learning:

- structs
- pointers
- arrays
- input handling
- modular programming in C
